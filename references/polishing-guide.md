# 书稿整理规范（Polishing Guide）

把 whisper 逐字稿整理成正式书稿的完整契约。整理是人工智慧的活，不是格式化——必须逐段读、逐段写。

## 输出格式契约（build_epub.py 依赖此约定）

```markdown
# 第N讲 标题（或文章标题）
> 原课程/原作者：<来源名>（<讲者/作者>）
> 视频链接：https://youtu.be/<id>
> 本文稿由课程音频转写整理而成，仅供个人学习使用

## 第一节标题（概括内容，不是"第一部分"这种空标题）
正文段落……

## 第二节标题
正文段落……
```

- 文件较长时：第一次用 Write 写头部+前几节，后续用 append 追加，最后通读自审。
- 正文可用 `**加粗**` 标关键词；不要图片、不要表格（EPUB 为纯文字版式）。
- 小节密度：每 2000–3000 字一节。

## 内容规则

1. **完整优先**：不省略任何知识点、论证、举例。只清理口语：语气词、重复句、口误、课堂寒暄（天气/点名/玩笑可删）。
2. **繁转简**：全转简体；古文引文保持原样并可按通行本校正。
3. **误识修正**：先查 `corrections-zh.md` 词典批量替换，再按上下文常识修正新误识（人名、书名、术语是重灾区）。新发现的误识必须回写词典（见 self-improvement.md）。
4. **无法确证的内容**（如听不清的人名）：稳妥处理——泛化为"有学者"或保留音译并标注存疑，绝不编造。
5. **自审清单**：简体转换彻底 / 误识修正完毕 / 章节结构完整 / 信息行三行齐全 / 体量与原稿相当。

## 体量基准

逐字稿字符数 ≈ 整理稿字符数 ×（1.0–1.2）。明显缩水说明漏了内容；明显膨胀说明注水。

## whisper 常见 artifacts

- 整块重复（同一段文字重复出现 2-3 次）：去重保留一份。
- 块接缝处的半句：与前一块末句合并。
- 时间轴缺失不影响整理——逐字稿已是纯文本行。
